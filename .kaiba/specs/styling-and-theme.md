# Styling and Theme

All styles MUST be embedded in a `<style>` block inside the `<head>` element. No external CSS files or frameworks (Bootstrap, Tailwind, etc.) are permitted.

## Colour Palette — Natural Earthy Tones

| Role | Colour |
|---|---|
| Stone greys | `#6b6b6b`, `#d4cfc9` |
| Sandy tan (nav links) | `#c2a97a` |
| Warm brown (section headings) | `#7a5c3e` |
| Off-white background | `#faf7f2` |

## Typography

- Base font size: 16px minimum
- Line spacing: 1.6–1.8
- Headings: serif or slab-serif font stack to reinforce the earthy, natural feel — e.g. `Georgia, 'Times New Roman', serif`
- Section headings use the warm brown accent colour (`#7a5c3e`)

## Layout

- Clean and readable with clear visual separation between sections (borders or spacing)
- Navigation links use sandy tan (`#c2a97a`) with underline on hover

## Accessibility (Colour Contrast)

Colour combinations must meet WCAG AA contrast ratios for normal and large text.
