# In-Page Navigation

The page MUST include an in-page navigation list using anchor links at the top of the page, allowing users to jump directly to each rock type section without scrolling.

- Navigation links must target the Igneous, Sedimentary, and Metamorphic rock sections at minimum
- Links must wrap gracefully on narrow screens (no overflow or horizontal scrolling)
- Navigation links should be styled using the sandy tan colour (`#c2a97a`) with underline on hover
