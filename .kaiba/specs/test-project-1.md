## 1. Overview

This specification describes the design and implementation of a dedicated HTML page targeting MacBook users. The page will be optimised for the display characteristics, input paradigms, and browsing conventions of Apple MacBook devices (all current screen sizes and generations). It serves as the primary deliverable for *test project 1*.

## 2. Architecture

### 2.1 Technology Stack

| Layer | Choice | Rationale |
|---|---|---|
| Markup | HTML5 | Semantic, standards-compliant structure |
| Styling | CSS3 (+ CSS variables) | Responsive layout, macOS-aligned aesthetics |
| Scripting | Vanilla JavaScript (ES2020+) | Zero dependency overhead for a single page |
| Fonts | System font stack (`-apple-system, BlinkMacSystemFont`) | Native macOS rendering, no external font load |

### 2.3 Rendering Target

- **Engine:** WebKit / Blink (Safari, Chrome on macOS)
- **Resolution baseline:** 2560 × 1600 (MacBook Pro 16″ Liquid Retina), 2560 × 1664 (MacBook Air M2), 2304 × 1440 (MacBook Pro 14″)
- **Pixel density:** 2× (Retina) — all raster assets must be provided at `@2x` minimum

## 4. Constraints

| ID | Constraint |
|---|---|
| C-01 | **Platform scope:** The page is scoped to MacBook devices only. Mobile, Windows, and external-monitor-only viewports are out of scope for this phase. |
| C-02 | **No build toolchain:** The deliverable is plain HTML/CSS/JS — no bundlers (Webpack, Vite, etc.) are required in this phase. |

| C-04 | **macOS system fonts only:** External web fonts shall not be loaded to preserve the native macOS look-and-feel. |
| C-05 | **Single page:** The deliverable is one HTML file (`index.html`) plus supporting assets — multi-page routing is out of scope. |

## 5. Scope

### 5.1 In Scope

- Responsive HTML5 page layout optimised for MacBook viewport widths (1280 px – 2560 px)
- Retina-ready CSS and asset pipeline (`@2x` image handling via `srcset`)
- macOS dark/light mode theming via CSS `prefers-color-scheme`
- Basic semantic structure: header, main content area, footer
- Trackpad-friendly scroll and hover interactions
- Accessibility markup (ARIA roles, keyboard navigation)
- Deployment as a static file to the `main` branch of `shuiiz/test-repo`

### 5.2 Out of Scope

- Mobile or tablet layouts
- Windows / Linux browser compatibility testing
- Backend APIs or dynamic data fetching
- Multi-page navigation or routing
- Analytics or third-party script integrations
- Internationalisation (i18n) / localisation (l10n)
