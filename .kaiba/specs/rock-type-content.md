# Rock Type Content Requirements

Each of the three rock type sections (Igneous, Sedimentary, Metamorphic) MUST include:

- **Definition** — What the rock type is, in plain language
- **Formation** — How it forms (e.g. cooling of magma, compression of sediment, heat/pressure transformation)
- **Characteristics** — Typical visual/physical properties a reader could recognise
- **Examples** — At least 3 named examples with a one-line description each (e.g. "Granite — a coarse-grained igneous rock common in continental crust")

## Target Audience

Content is intended for **both general public / casual readers and students**:
- Use clear, everyday language accessible to any adult reader
- Provide enough geological depth to be useful as a learning resource (e.g. for school/study)
- Avoid unexplained jargon — define technical terms inline when first used
